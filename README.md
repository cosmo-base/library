# Cosmo Base 資料館 運用マニュアル 🚀

このリポジトリは、Cosmo Base（未来宇宙産業フォーラム）のコミュニティ内限定で資料を公開・検索するための「資料館」Webサイトのソースコードを管理しています。

資料自体は重くならないようGoogle Driveに保存し、当サイトは「検索と一覧表示（カタログ）」の役割を担います 。

## 📂 ファイル構成

* `index.html` : サイトの骨組み（デザイン構造）
* `style.css` : サイトの見た目（色、レイアウト）
* `script.js` : 検索、絞り込み、ランキング表示などの動作プログラム
* **`data.json` : 資料のデータ一覧（※日常的な更新はこれだけを触ります）**
* `update_ranking.py` : GA4から閲覧数を取得する自動化プログラム
* `.github/workflows/` : 閲覧数ランキングの自動更新を指示する設定ファイル

## 📝 新しい資料の追加方法

新しい資料が完成し、サイトに掲載する際の手順です。プログラムの知識は不要で、GitHubの画面上から直接編集できます。

### Step 1: Google Driveのリンク取得
1. 掲載したい資料をGoogle Driveの共有フォルダにアップロードします。
2. ファイルの共有設定を **「リンクを知っている全員（閲覧者）」** に変更し、リンクをコピーします。

### Step 2: `data.json` の編集
1. このGitHubリポジトリの `data.json` を開きます。
2. 右上の **鉛筆アイコン（Edit this file）** をクリックします。
3. 既存の資料データ `{ ... }` を一つコピーし、一番下（または一番上）に貼り付けて、中身を新しい資料の情報に書き換えます。

**▼ コピー用テンプレート**
```json
  {
    "id": "ID",
    "title": "資料のタイトル",
    "date": "YYYY-MM-DD",
    "author": "作成者の名前",
    "type": "資料種類",
    "summary": "資料の簡単な説明文。（対象：〇〇な人）",
    "url": "Google Driveのリンク",
    "tags": {
      "level": "対象レベル",
      "category": "カテゴリ",
      "others": ["スターターキット", "など任意のタグ"]
    },
    "views": 0
  }
```

### Step 3: 変更を保存（反映）
1. 書き換えが終わったら、右上の緑色のボタン 「Commit changes...」 を押します。
2. そのままもう一度 「Commit changes」 を押せば完了です。
3. 1〜2分後にWebサイトが自動更新され、新しい資料が一覧や新着に表示されます。

## `id` の設定方法
`イベント資料`：`E-01`,`E-02`,...  
`週刊ニュース`：`N-01`,`N-02`,...  
`イベント報告書`：`R-01`,`R-02`,...  
`イベントレポート`：`r-01`,`r-02`,...  
`宇宙解説資料`：`s-01`,`s-02`,...  

## 🏷️ 使用できるタグのルール（完全一致必須）
絞り込み検索を正常に機能させるため、`type`, `level`, `category` の項目は以下の決められた文字を一言一句間違えずに入力してください。

* 資料種類 (`type`)  
  `イベント資料`, `週刊ニュース`, `イベント報告書`, `イベントレポート`, `宇宙解説資料`
* 対象レベル (`level`)  
  `初心者`, `中級者`, `上級者`
* カテゴリ (`category`)  
  `宇宙開発`, `天文・観測`, `宇宙ビジネス`, `エンタメ`, `その他`

※ `others`（その他のタグ）には、自由に文字を入れて複数設定できます。不要な場合は `[]` と空にしておきます。

## 🏆 ランキングの自動更新について
資料の閲覧数ランキングは、Google Analytics (GA4) のデータを用いて 毎日 日本時間の深夜0時に自動で集計・更新 されます（GitHub Actionsを使用）。
これにより、人気に基づいた資料作成の参考にすることが可能です 。

手動で今すぐランキングを最新にしたい場合：
1. リポジトリ上部の 「Actions」 タブを開きます。
2. 左側のメニューから 「Update Ranking Data」 を選択します。
3. 右側の 「Run workflow ▽」 を押し、緑色の 「Run workflow」 ボタンをクリックします。
4. 1分ほどで処理が完了し、サイトのランキング順位が最新化されます。

## ⚠️ 注意事項・トラブルシューティング
* サイトが表示されなくなった / 新しい資料が出ない
  `data.json` の書き間違え（カンマ `,` の付け忘れ、不要なカンマの消し忘れ、ダブルクォーテーション `"` の欠落）が原因の99%です。最後に編集した箇所を見直してください。最後のデータの終わりにはカンマを付けないルールになっています。

* Google Cloud / GA4 の設定を変更しないでください
  自動更新システムは、特定のアカウント（サービスアカウント）とGA4のプロパティIDが連携して動いています。GitHubの `Settings > Secrets` に登録されている鍵情報は消去・変更しないようご注意ください。
