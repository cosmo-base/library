# Cosmo Base 資料館 運用マニュアル 🚀

このリポジトリは、Cosmo Base（未来宇宙産業フォーラム）のコミュニティ内限定で資料を公開・検索するための「資料館」Webサイトのソースコードを管理しています。

資料自体は重くならないようGoogle Driveに保存し、当サイトは「検索と一覧表示（カタログ）」の役割を担います。
**※資料のデータ管理（追加・編集）は、専用の Googleスプレッドシート で行っています。**

## 📂 ファイル構成（GitHub側）

* `img/` : サムネイル画像を入れるフォルダ 🖼️
* `index.html` : サイトの骨組み（デザイン構造）
* `sub.html` : 絞り込み結果や各一覧を表示する専用ページ
* `style.css` : サイトの見た目（色、レイアウト）
* `script.js` : 検索、絞り込み、ランキング表示などの動作プログラム
*(※日常的な資料の追加・編集はGitHubを触る必要はありません)*

---

## 📝 新しい資料の追加方法

新しい資料が完成し、サイトに掲載する際の手順です。プログラムの知識は不要で、**Googleスプレッドシートに1行追加するだけ**で完了します。

### Step 1: Google Driveのリンク取得
1. 掲載したい資料をGoogle Driveの共有フォルダにアップロードします。
2. ファイルの共有設定を **「リンクを知っている全員（閲覧者）」** に変更し、リンクをコピーします。

### Step 2: サムネイル画像のアップロード（※任意）
専用のサムネイル画像を設定したい場合は、以下の手順で画像をアップロードします。
（※設定しない場合は、自動でデフォルト画像 `CBlibDef.png` または週刊ニュース専用画像が表示されます）
1. このGitHubリポジトリの **`img` フォルダ** を開きます。
2. 右上の「Add file」＞「Upload files」をクリックし、画像（.jpg や .png など）をアップロードして保存（Commit）します。

### Step 3: スプレッドシートへの入力
[「Cosmo Base資料館 データ管理用スプレッドシート」](https://docs.google.com/spreadsheets/d/1QtgJJiX1dBq_jXtbEgD88v9ZgSCcZSr2cObcnglKsNQ/edit) を開き、一番下の空いている行に新しい資料の情報を入力します。
入力すると自動的にサイト側（CSV）に反映されるため、特別な保存作業は不要です。

## 🌟 各項目の入力ルール（スプレッドシート）

* **`id`**: 以下のルールで設定してください。
  * `イベント資料`：`E-01`,`E-02`,...  
  * `週刊ニュース`：`N-01`,`N-02`,...  
  * `FSIF活動報告書`：`F-01`,`F-02`,...  
  * `イベントレポート`：`R-01`,`R-02`,...  
  * `宇宙解説資料`：`S-01`,`S-02`,...
* **`title`**: 資料のタイトル
* **`image`**: 専用画像を設定する場合はファイル名（例: `image.png`）を入力。不要な場合は**空欄**。
* **`url`**: 取得したGoogle Driveのリンク
* **`isRecommend`**: おすすめページに表示したい場合は `TRUE` と入力。通常表示のみの場合は**空欄**。
* **`keywords`**: 検索に引っかけたい裏キーワード（目次など）があれば、カンマ区切りで入力します（例: `アルテミス計画,宇宙条約`）。

## 🏷️ 使用できるタグのルール（完全一致必須）
絞り込み検索を正常に機能させるため、以下の項目は決められた文字を一言一句間違えずに入力してください。

* **資料種類 (`type`)** * `イベント資料`: 保有コンテンツにて使用した資料
  * `週刊ニュース`
  * `FSIF活動報告書`: FSIF主催イベント、出展イベントの報告書
  * `イベントレポート`: 個人で行ったイベントのレポート
  * `宇宙解説資料`: 宇宙について等をまとめた資料
* **対象レベル (`level`)** `初心者`, `中級者`, `上級者`
* **カテゴリ (`category`)** `宇宙開発`, `天文・観測`, `宇宙ビジネス`, `エンタメ`, `ニュース`,`パートナー`,`その他`
* **その他のタグ (`others`)** 自由に文字を入れて複数設定できます。複数ある場合は **カンマ（`,`）区切り** で入力してください。不要な場合は空欄でOKです。

## 🏆 ランキング（閲覧数）の自動更新について
資料の閲覧数（`views`列）は、Google Analytics (GA4) のデータを用いて **Google Apps Script (GAS) が毎日自動で集計・累計加算** します。
これにより、人気に基づいた資料作成の参考にすることが可能です。

**手動で今すぐ閲覧数を最新にしたい場合：**
1. スプレッドシートの上のメニューから **「拡張機能」＞「Apps Script」** を開きます。
2. 画面上部の **「▷ 実行」** ボタンを押します。
3. 数秒後にログに「閲覧数の更新（累計加算）が完了しました！」と出れば、スプレッドシートのM列（views）が最新化されます。

## ⚠️ 注意事項・トラブルシューティング
* **サイトが表示されなくなった / 新しい資料が出ない**
  スプレッドシートの1行目（ヘッダー行：id, title など）の文字を書き換えてしまうと、プログラムがデータを読み込めなくなります。1行目は絶対に変更しないでください。また、行の途中に完全に空白の行を作らないようにしてください。
* **閲覧数がうまく取得できない（GASのエラー）**
  GASを実行した際に権限エラーが出る場合は、スプレッドシートを開いているGoogleアカウントが「GA4の閲覧権限を持っているアカウント（Cosmo Base運用アカウントなど）」になっているか、右上のアイコンから確認してください。
