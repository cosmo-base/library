# Cosmo Base 資料館 運用マニュアル 🚀

このリポジトリは、Cosmo Base（未来宇宙産業フォーラム）のコミュニティ内限定で資料を公開・検索するための「資料館」Webサイトのソースコードを管理しています。

資料自体は重くならないようGoogle Driveに保存し、当サイトは「検索と一覧表示（カタログ）」の役割を担います 。

## 📂 ファイル構成

* `index.html` : サイトの骨組み（デザイン構造）
* `style.css` : サイトの見た目（色、レイアウト）
* `script.js` : 検索、絞り込み、ランキング表示などの動作プログラム
* **`data.json` : 資料のデータ一覧（※日常的な更新はこれだけを触ります）**
* `update_ranking.py` : GA4から閲覧数を取得する自動化プログラム
* `.github/workflows/` : 閲覧数ランキングの自動更新を指示する設定ファイル

---

## 📝 新しい資料の追加方法

新しい資料が完成し、サイトに掲載する際の手順です。プログラムの知識は不要で、GitHubの画面上から直接編集できます。

### Step 1: Google Driveのリンク取得
1. 掲載したい資料をGoogle Driveの共有フォルダにアップロードします。
2. ファイルの共有設定を **「リンクを知っている全員（閲覧者）」** に変更し、リンクをコピーします。

### Step 2: `data.json` の編集
1. このGitHubリポジトリの `data.json` を開きます。
2. 右上の **鉛筆アイコン（Edit this file）** をクリックします。
3. 既存の資料データ `{ ... }` を一つコピーし、一番下（または一番上）に貼り付けて、中身を新しい資料の情報に書き換えます。

**▼ コピー用テンプレート**
```json
  {
    "id": "通し番号や任意のID",
    "title": "資料のタイトル",
    "date": "YYYY-MM-DD",
    "author": "作成者の名前",
    "type": "資料種類",
    "summary": "資料の簡単な説明文。（対象：〇〇な人）",
    "url": "Google Driveのリンク",
    "tags": {
      "level": "対象レベル",
      "category": "カテゴリ",
      "others": ["10分", "必読", "など任意のタグ"]
    },
    "views": 0
  }
